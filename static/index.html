About DocRAG

DocRAG is an intelligent document understanding assistant designed for deep comprehension, synthesis, and accurate citation-grounded question answering over PDF files.

🧠
Intent-Aware Query Understanding

Automatically recognizes summarization and overview requests ("summary", "explain this PDF", "key points") and synthesizes across document sections rather than failing similarity thresholds.

🎯
Verified Page References

Every answer includes 1-indexed document page references and exact quoted excerpts for quick verification.

🔒
Ephemeral RAM Privacy

Documents and vector indices reside in memory per session and reset automatically on idle. No data is stored persistently.
